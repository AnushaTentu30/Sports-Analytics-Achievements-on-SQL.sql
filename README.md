
# 🏏 IPL Sports Analytics using SQL

This project analyzes historical IPL data using SQL to uncover team performance trends, player stats, venue impacts, and match outcomes.

## 🔧 Tools & Skills
- SQL (MySQL/PostgreSQL)
- Data Cleaning
- Aggregations, Joins, Subqueries
- Sports Analytics

## 📊 Key Insights
- Top performers by season and venue
- Team win rates and run rate comparisons
- Venue-based performance trends

## 📁 Files
- `Sports Analytics using SQL.sql` – All SQL queries used for data analysis.

## 📌 Summary
A sports analytics project aimed at extracting meaningful insights from IPL datasets using structured SQL queries.
